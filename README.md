# Camp-Points-Guide
和平精英经典海岛苟分点合集
地图标点：可在海岛任意位置标记苟分点，点击标记弹出详情。
点位详情：展示所在区域、类型、风险等级、文字描述、实战要点（最多 6 条）以及图片画廊（支持灯箱放大）。
自定义：地图上选点、填写名称/区域/类型/风险，上传多张图片（前端自动压缩后上传）。
搜索与筛选：按关键词搜索（点位名、地名、描述），按类型筛选（建筑制高点、野区隐蔽、海边悬崖、水下特殊、桥梁载具）。
地图操作：鼠标滚轮缩放（1x–8x，以光标为中心）、按住拖动平移、一键重置，缩放时标记保持恒定大小。
双视图：地图视图与卡片列表视图一键切换。
抗毒技巧：附各圈毒外满状态存活时间与进圈节奏参考。
数据持久化：点位与图片存服务端 SQLite，多浏览器、多设备共享同一份数据。
